# Data Science – Course Repository

This repository contains all materials related to the **Data Science** course.  
It combines theoretical foundations with practical applications, assignments, projects, and final exam resources.

---

## 📂 Repository Structure

- **Data Science Slides**  
  Lecture slides covering all theoretical topics in the course.

- **Assignments**  
  Individual assignments combining theory and practice:  
  - Assignment 1 – Web Scraping  
  - Assignment 2 – Preprocessing & Visualization  
  - Assignment 3 – Machine Learning (Classification & Regression)

- **Projects**  
  Final project applications and reports:  
  - Student Impact Dataset (Classification & Regression)  
  - AyatStore Products Dataset (Clustering)

- **Books & References**  
  - Hands-on Introduction to Data Science (PDF)  

- **Exams**  
  - Data Science Final Exam (questions and solutions)  

---

## 🛠️ Tools & Technologies
- **Python (Pandas, NumPy)** – for data preprocessing and analysis  
- **Matplotlib & Seaborn** – for visualization  
- **Scikit-learn** – for machine learning models (Decision Tree, Linear Regression, KMeans)  
- **Web Scraping (BeautifulSoup, Requests)** – for collecting raw data from websites  

---

## 🎯 Learning Outcomes
By working through this repository, students will:  
- Understand the complete Data Science workflow (collection, cleaning, visualization, modeling, evaluation).  
- Apply preprocessing techniques to handle missing values, duplicates, and data types.  
- Visualize data distributions and relationships using plots.  
- Implement machine learning models for classification, regression, and clustering.  
- Evaluate models using accuracy, precision, recall, R², and MSE.  
- Gain practical experience with real datasets and web scraping.
